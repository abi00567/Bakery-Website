 Bakery Website – Full Stack Web Application

 Project Overview

The Bakery Website is a full-stack web application developed to simplify online bakery shopping. It enables customers to browse bakery products, register and log in securely, add products to a shopping cart, and place online orders. The system also provides an admin interface to manage products, inventory, and customer orders efficiently.

---
Project Objectives

* Develop a responsive bakery website.
* Provide secure user registration and login.
* Display bakery products with images and prices.
* Enable online ordering through a shopping cart.
* Store customer and order details in a database.
* Improve customer experience through digital ordering.
